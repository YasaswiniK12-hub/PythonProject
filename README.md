# 🐍 Python Fundamentals & Projects

Welcome to my Python learning repository! This repository contains all the code, exercises, and mini-projects completed during **Mike Dane's FreeCodeCamp Python Course**. 

The files are structured sequentially following the course curriculum—from basic data types and control structures to File I/O, Modules, and Object-Oriented Programming (OOP).

---

## 📚 Curriculum & Repository Guide

### 1. Fundamentals & Variables
- `app.py` – Working with numbers, strings, and core print operations.
- `Getting_Input_From_Users.py` – Capturing and handling user input.
- `Comments.py` – Syntax and best practices for writing comments in Python.

### 2. Early Mini-Projects
- `Basic_Calculator.py` – Building a simple two-number addition calculator.
- `Mad_Libs_Game.py` – Interactive word game using user inputs.

### 3. Data Structures
- `List.py` – Creating, modifying, and using list methods.
- `Tuples.py` – Working with immutable sequence data types.
- `Dictionaries.py` – Key-value pairs and dictionary lookups.

### 4. Functions & Conditional Logic
- `Functions.py` – Defining functions and passing parameters.
- `Return.py` – Returning values back from functions.
- `If_Statements.py` – Logical operators (`and`, `or`, `not`) and conditional execution.
- `If_Comparisons.py` – Comparison operators (`==`, `!=`, `>`, `<`).
- `Better_Calculator.py` – Advanced calculator handling multiple arithmetic operators (`+`, `-`, `*`, `/`, `%`).

### 5. Loops, Algorithms & Logic Games
- `While_loop.py` – Understanding `while` loops and iteration conditions.
- `Guess_Game.py` – Interactive guessing game built using `while` loops and conditionals.
- `for_loop.py` – Iterating over ranges, lists, and strings.
- `Exponent_Function.py` – Custom exponential calculator using `for` loops.
- `2D&Nested_Loops.py` – Accessing multi-dimensional lists using nested loops.
- `Translator.py` – Building a custom translator function (replacing vowels).

### 6. File Handling & Error Management
- `Try/` – Exception handling using `try...except` blocks.
- `Reading_Files.py` – Reading data line-by-line from text files.
- `Writing_toFiles.py` – Writing and appending data to files.
- `employees.txt` – Sample text file used for file reading/writing exercises.

### 7. Modules & PIP
- `useful_tools.py` – Helper functions module.
- `Modules_and_PIP.py` – Importing custom modules and external packages.

### 8. Object-Oriented Programming (OOP) & Projects
#### **Classes & Objects**
- `Student.py` – Class definition with properties.
- `Student_Object.py` – Instantiating student objects.
- `Object.py` & `Object_Functions.py` – Implementing class functions and instance methods.

#### **Multiple Choice Quiz Project**
- `Question.py` – Question class model.
- `MCQ.py` – Quiz engine using class instances and scoring logic.

#### **Inheritance & Method Overriding**
- `Chef.py` – Base class representing general cooking operations.
- `Chinese_Chef.py` – Subclass demonstrating inheritance and method overriding.
- `ChefObject.py` – Driver script testing inherited and overridden methods.
